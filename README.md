Tetris

Features:
- Modern Tetris mechanics
- 7-bag randomizer
- Hold queue
- Ghost piece
- Sprint mode (40 lines)
- Marathon mode
- 0 ARR emulation with Latest Input Priority
- Adjustable DAS, ARR, and SDF
- Infinite soft drop
- Real-time input display
- Customizable keybindings
- Customizable piece colors
- Master saturation, brightness, and hue controls
- Adjustable ghost piece opacity
- Customizable UI background color
- Background image URL support
- Dark and light modes
- Motion sickness mode
- Adjustable grid opacity
- Multiple font options
- Practice (Zen) mode
  - Instant resetting and no countdowns
  - Perfect Clear (PC) counter
  - Gravity toggle (On/Off)
  - Undo (`Ctrl+Z`) and Redo (`Ctrl+Y`) with smooth board rotation animations
- Super Rotation System (SRS) accuracy improvements (lock delay resets)
- Spawn collision and hold piece bug fixes
